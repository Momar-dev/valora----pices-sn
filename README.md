# VALORA ÉPICES'SN — Site Officiel & Vitrine Web

Plateforme numérique et application mobile d'accompagnement en valorisation des matières premières agricoles, transformation agroalimentaire et calcul de rentabilité pour les femmes et les jeunes entrepreneurs au Sénégal.

## 🌿 À propos de VALORA

VALORA est conçue pour résoudre le défi des pertes post-récolte en Casamance et au Sénégal en guidant pas à pas les transformatrices et entrepreneurs :
- **Identification & Fiches de transformation :** valorisation des récoltes locales (mangue, bissap, gingembre, épices, etc.).
- **Calculateur d'intrants réels :** chiffrage précis du coût de revient et fixation du prix de vente avec marge recommandée.
- **Formations & Hygiène :** modules pratiques aux standards sanitaires et techniques de conservation.
- **Débouchés commerciaux :** orientation vers les circuits de vente adaptés.

## 🚀 Démarrage local

### Prérequis
- Node.js (version 18 ou supérieure recommandée)
- npm ou yarn

### Installation
```bash
npm install
```

### Lancement du serveur de développement
```bash
npm run dev
```
L'application est accessible à l'adresse [http://localhost:3000](http://localhost:3000).

### Construction pour production
```bash
npm run build
```
